\section{Methodology}
\label{sec:methodology}

The aim of this work is to optimize the topology of a truss structure, given a set of constraints and a set of loads.

In the following sections, we will at first give an overview of the topology optimization problem, describing the main concepts and the mathematical foundations needed.

Then, we will present a couple of examples of truss structures, showing how the optimization problem can be formulated and solved in practice.
In particular, we will show the results obtained using our custom implementation of CONLIN algorithm for the optimization of:

\begin{enumerate}
    \item Cantilever rods structure (single load case)
    \item Motorcycle frame structure (multiple load case)
\end{enumerate}
